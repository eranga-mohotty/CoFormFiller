🛡️ Ollama Security & Origin Setup

By default, Ollama blocks browser requests. To safely allow only this extension without exposing your local Ollama instance to other websites or extensions, start Ollama with your exact extension origin:

OLLAMA_ORIGINS="chrome-extension://..." ollama serve
Windows (PowerShell): $env:OLLAMA_ORIGINS="..."; ollama serve
